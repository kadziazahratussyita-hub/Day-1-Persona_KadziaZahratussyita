## 2. Deskripsi Repository
Repository ini dibuat untuk menyimpan dokumentasi dan catatan kegiatan Workshop Day 1 dengan tema Building with AI, Managing Change with GitHub. Isi repository mencakup rangkuman materi, pengetahuan baru yang diperoleh, serta dokumentasi proses pengembangan proyek sederhana menggunakan bantuan AI dan GitHub.
## 3. Tujuan:
- Mengumpulkan dan menyimpan hasil dokumentasi workshop secara terstruktur.
- Menjadi tempat untuk melihat kembali materi yang telah dipelajari.
- Mendokumentasikan proses pembuatan dan pengembangan proyek.
- Melatih penggunaan Git dan GitHub untuk mengelola perubahan serta menyimpan proyek secara online.
## 4.Informasi Kegiatan Workshop
Workshop Day 1 membahas penggunaan AI dalam proses pembuatan aplikasi serta pengenalan Git dan GitHub untuk mengelola perubahan proyek. Materi yang disampaikan meliputi prompt engineering, cara membuat prompt yang jelas dan spesifik, pengertian Git dan GitHub, repository, commit, branch, pull request, serta alur kerja Git.

Pada kegiatan praktik, peserta diarahkan untuk membuat proyek sederhana berupa Student Task Planner, yaitu aplikasi web untuk membantu mahasiswa mengatur tugas dan tenggat waktu. Peserta juga diperkenalkan dengan penggunaan AI-assisted platform, Git, dan GitHub untuk membuat, menyimpan, serta memperbarui proyek.

## 5.DOKUMENTASI KEGIATAN WORKSHOP
## 1. Rangkuman Materi Workshop
Dengan menggunakan prompt yang jelas dan terstruktur, hasil yang diberikan AI dapat menjadi lebih relevan dan sesuai kebutuhan. Materi workshop membahas Prompt Engineering, yaitu teknik menyusun instruksi AI agar menghasilkan jawaban sesuai kebutuhan dengan struktur role, task, context, dan format. Selain itu, peserta mempelajari Git sebagai alat untuk melacak perubahan file dan GitHub sebagai platform penyimpanan repository secara online. Materi juga mencakup Git Workflow yang terdiri dari Working Directory, Staging Area, dan Repository, serta penggunaan perintah dasar Git seperti git init, git add, git commit, git push, git pull, dan git clone. Peserta juga mempelajari pengaturan Git, penggunaan VS Code, serta cara menghubungkan akun GitHub melalui SSH.
## 2. Poin-Poin Penting
- Memahami cara membuat prompt AI yang efektif.
- Mengetahui perbedaan Git dan GitHub.
- Memahami fungsi repository.
- Mengetahui cara menyimpan perubahan menggunakan Git.
- Memahami penggunaan GitHub sebagai media dokumentasi proyek.
